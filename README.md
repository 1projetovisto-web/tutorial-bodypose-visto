V.I.S.T.O | Tutorial BodyPose
Este repositório contém um material de apoio pedagógico interativo para o primeiro contato com programação criativa e inteligência artificial.

🌟 O que é?
Uma interface amigável projetada para explicar o código de rastreamento corporal (ml5.js) de forma visual e intuitiva. Através de "pincéis somáticos", transformamos a lógica de programação em uma experiência videocoreográfica.

🚀 Funcionalidades
Tooltips Explicativos: Passe o cursor (ou toque no mobile) sobre as linhas de código para entender o que cada função faz.

Identidade V.I.S.T.O: Estética de terminal neon focada no conforto visual e aprendizado.

Multiplataforma: Versões otimizadas para desktop e dispositivos móveis.

📂 Arquivos Principais
index.html: Tutorial interativo para Desktop (foco em hover).

index_mobile.html: Tutorial otimizado para Smartphones (foco em toque).

🛠️ Tecnologias
HTML5 / CSS3 (Custom Properties & Glassmorphism)

JavaScript

p5.js

ml5.js (BodyPose Model)

Este projeto faz parte do ecossistema V.I.S.T.O | Ocupações Videocoreográficas.
